# ふるさと納税のコーナーと返礼品

ふるさと納税のページの決めごと・計算・経緯と、返礼品のページのしくみ。URL や名前で検索して、さわる所だけ読む。

## 返礼品のしくみ（楽天の商品検索API）
- 返礼品のページのしくみのくわしいこと
- 返礼品のページ（10/22 第3弾）：楽天市場の商品検索API（2026-07-01版。applicationId・accessKey・affiliateId と Referer）で、**公開のときにビルドの中で取ってHTMLにするだけ**。取ったデータ（`.henreihin/`）はコミットしない・成果物に上げない・ログには件数だけ（楽天ウェブサービスの規約 第10条9号）。ビルドが終わったら消す
  - モード（`scripts/henreihin-mode.mjs`）：`HENREIHIN_LIVE` が true でキーがあれば api（本番もPRも楽天のデータ）、まだのときの PR は fixture（`tests/fixtures/henreihin.json` の作り話の見本の商品。noindex と「見本」の帯）、ほかは off（ページを作らない）。手元では `HENREIHIN=fixture npm run build` で見本のページを作れる
  - 取れなかったとき・量が読めた返礼品が5件より少ない一覧があるときは、公開を止める（前の公開がそのまま残る）
  - 毎日の取り直し：`.github/workflows/henreihin-daily.yml` が日本時間6:07（12月は18:07も）に本番の公開を動かす。LIVE のときは、本番の公開のあとに、いまの本番以外で3日より古い公開を消す（古いプレビューに楽天の情報を残さない）
  - Secrets：`RAKUTEN_APPLICATION_ID`・`RAKUTEN_ACCESS_KEY`・`RAKUTEN_AFFILIATE_ID`（しょーくんが GitHub に直接入れる。チャットに貼らない）。10/22 に楽天のアプリ「サクッと計算」を登録して入れた。アプリの有効期限は **2027年10月22日**（その前に楽天のアプリ一覧で「有効期限延長」。切れると毎日の取り直しが止まる）。楽天アフィリエイトのサイト登録もした（3位）
  - 10/22 本物で確かめたこと：人気の返礼品は8〜9割が「5kg / 10kg / 20kg 選べる」のように量や回数を選べるもので、楽天の寄付額がどの量の額かわからない。しょーくんが「量が決まったものだけ」をえらんだので、`readAmount` は量や回数をえらぶもの・幅・下だけの量（600g〜）・「各250g」・ほかの物とのセットを出さない。長巻きのトイレットペーパーは、ふつうの長さで何ロール分か（`ロール分`）。言葉だけだと「米に合う」しらすや、こめ油も入るので、楽天のジャンルでしぼる（`genreId`）。量が決まったものを集めるために10ページ（300件）取る
  - 本物の名前を見て読み取りを直したいとき（10/22 にやった方法。スクリプトはもう消した）：一時的なワークフローで、楽天から取った名前を Claude の手元だけにある鍵で暗号にしてPRのコメントに置き、Claude が読んだらすぐコメントを消す。ログ・成果物・リポジトリに読める形で残さない。テストの名前は作り話にする
  - `henreihin-check.yml` は、手で動かすほかに、返礼品の探し方（`src/data/henreihin.mjs`・`src/lib/henreihin.mjs`・`scripts/rakuten.mjs`）を変えたPRでも動く（main にない workflow_dispatch は動かせないので）
  - 本番に出す手順：しょーくんが楽天のアプリ登録（アプリ名 サクッと計算・URL と許可されたWebサイトは sakutto-keisan.com・楽天市場API）と、楽天アフィリエイトのサイト登録をして、Secrets を入れる → Claude が `henreihin-check.yml` を手で動かして、件数・ふるさと納税の店の数・多いジャンルIDを注意書きで見る → `genreId` を入れる → `HENREIHIN_LIVE = true` のPR → プレビューで量の読み取りを、しょーくんといっしょに目で見る → Merge

## コーナーのページ
- ふるさと納税のコーナー（10/22 しょーくん「ふるさと納税・楽天SPUをサクッと計算のコーナーに」。設計はプロジェクトの `claude/sakutto-tougou-plan.md`、元の資料は `claude/furusato-*.md`）：カテゴリ `furusato`（テーマはお仕事・お金と同じ紺の手帳）。URL は入れ子（`tools.mjs` の `path`。/furusato/、/furusato/jougen/）で「rakuten」をパスに入れない。11〜12月にビルドすると「よく使う計算」の8つ目（実質単価）が「ふるさと納税」に入れかわる（`pickSeason`。1月の最初のビルドで元にもどる）。決まり：公的な出典と確認日をページに出す（`FURUSATO_SOURCES`。確認日から90日、11〜1月は30日をこえるとテストが止まるので、本文を開いて確かめ直して checked を直す）。計算は「目安」と書き、最後は決定通知書か市区町村で確かめると書く。税理士の監修ではない。ポイントのお得さは書かない
  - 上限の目安 `/furusato/`（はじめての3問）：年収（万円）と、配偶者（ひとり・共働き／夫婦＝配偶者を扶養）と、扶養している16歳以上の子（なし・高校生・大学生・両方）のマス。家族ははじめから「ひとり」「子なし」をえらんでおく。計算は `src/lib/furusato.mjs`：給与だけ・社会保険料は年収の15%・ほかの控除なしと仮定。住民税の所得割（市6%・県4%を100円未満切り捨て、調整控除のあと）× 20% ÷（90% − 所得税率 × 1.021）＋ 2,000円を1,000円未満切り捨て。所得税率は「住民税の課税所得 −（調整控除の人的控除の差＋所得税の基礎控除から48万円を引いた額）」の帯（各務原市・練馬区）。年収850万円をこえて子がいると所得金額調整控除。所得割がかからない人は「—」。前の年の税制にした数字で、ふるなびの早見表（2024年・調整控除あり）の300〜900万円×7つの家族がすべて同じになることをテストで確かめた（2026年の数字は手でも確かめた）。結果は住民税の書類ふう（大きな上限、お金の流れ「今年中に寄付 → 翌年6月から住民税が減る → 自己負担2,000円」、手続き）。本文は年収×家族の早見表（ひとり・共働き／夫婦の2つの表）
  - 控除上限額の計算 `/furusato/jougen/`：住民税の決定通知書の所得割と、所得税率のマス（5〜45%、下に課税される所得の帯）から。結果は所得割×20%・特例控除の割合・住民税から減る額の表。個人事業主・年金の人は納税通知書の所得割で使える（よくある質問）
  - ふるさと納税に必要な年収 `/furusato/nenshu/`（10/23 検索候補の調べ「5万円 年収」など。討論はプロジェクトの `claude/sakutto-chishiki-debate-2026-10-23.md`。トップでは「ほかの計算」にたたむ）：寄付したい額（円）と、上限の目安と同じ家族のマス（`FAMILY_TILES`）から、上限がその額に届くいちばん低い年収（`furusatoIncomeFor`。上限は年収とともに増えるので、1万円きざみで2つに分けて探す。テストで、1万円ずつ見たときと同じことと、上限が年収とともに減らないことを確かめる）。結果は上限の目安と同じ書類とお金の流れ。本文は寄付額（1万〜100万円）×家族の早見表。上限の目安のよくある質問の「年収いくらから」の数字（上限が1万円になる年収）も、この計算から出す
  - 共働き・夫婦の上限 `/furusato/fuufu/`（10/23 しょーくんが「ページを作る」をえらんだ。トップでは「ほかの計算」）：あなたの年収・配偶者の年収（0もよい）・扶養している16歳以上の子のマスと、子をえらんだときだけ出る「子を扶養する人」のマスから、それぞれの上限と合計（`furusatoCouple`）。配偶者の年収から配偶者控除（配偶者の合計所得62万円以下＝給与だけなら136万円まで）か配偶者特別控除（133万円以下＝207万円まで。所得税・住民税の表は `FURUSATO_YEARS` の `spouseSpecialIncomeTax`・`spouseSpecialResident`、調整控除の人的控除の差はない）を、年収の多いほう（同じならあなた）の計算に入れる（`furusatoLimit` の `spouseIncome`）。おたがいには受けない（国税庁 No.1195）。出典は `FURUSATO_FUUFU_SOURCES`（国税庁・名古屋市・日の出町・綾川町）。結果は書類（大きな2人の合計、合計の帯を2人に分けた絵、それぞれの上限、どちらがどの控除か）。本文は配偶者の年収（なし・150・200・300万円）× あなたの年収の早見表
  - 控除の内わけ `/furusato/uchiwake/`（10/23 しょーくんが「11月中に作る」をえらんだ。検索候補「自己負担 2000円」「仕組み 図解」。トップでは「ほかの計算」）：寄付の合計・年収・家族のマスから、寄付額を所得税（（寄付−2,000円）× 所得税率 × 1.021。所得税がかからない人は0、所得税の額まで）・住民税の基本分（10%）・特例分（（90% − 所得税率 × 1.021）を所得割の20%まで）・自己負担に分ける（`furusatoBreakdown`。1円未満は四捨五入。税率が同じなら特例分は残りを埋めて、上限までの寄付の自己負担はちょうど2,000円）。結果は書類（大きな自己負担、寄付額の帯を4色＋上限をこえた分の斜線、表）。本文は年収500万円・ひとりの寄付額ごとの内わけの表
  - 第2弾（10/22。しょーくん「どんどん開発続行して」）：ページは `src/pages/furusato-tetsuzuki.mjs`、計算は `src/lib/furusato-tetsuzuki.mjs`・`furusato-memo.mjs`。3つとも親はコーナー（パンくずは「ホーム › ふるさと納税の上限の目安 › ◯◯」）で、トップでは寄付メモをそのまま、ワンストップ特例・締め切り・控除上限額は「ほかの計算」にたたむ。期限は見た人のブラウザの今日から（`furusatoDeadlines`：1月1日〜10日は前の年の寄付の申請、3月15日までは前の年の確定申告。3月15日が土日なら次の月曜、1月10日は土日でも同じ）
    - ワンストップ特例の申請 `/furusato/onestop/`：寄付先の数（−／＋）と、確定申告（しない・する）とマイナンバーカード（あり・なし）のマス。結果は書類（寄付先に出す◯通、期限とあと何日、寄付先ごとの封筒の絵で6通目からは赤い斜線、封筒の中と出す先）。6つ以上か確定申告なら「特例は使えません」と確定申告の期間。申請書は寄付ごと、同じ年の同じ自治体は1つと数える（総務省の通知）
    - ふるさと納税はいつまで `/furusato/shimekiri/`：手続きのマス（ワンストップ・確定申告）。結果は2枚の日めくり（年内の寄付と、申請書の必着か確定申告の終わり）と、近いほうの「あと◯日」をいちばん大きく。年内の寄付は12月31日までに入金・決済したもの（函館市）
    - 寄付メモ `/furusato/memo/`：上限（上限の目安の結果の「寄付メモ」から開くと `#limit=…&y=…` で入る。# のうしろはサーバーに送られない）と、行ごとの自治体・金額・申請書の「未／済」（3行から「＋1つ追加」で30行まで）。結果は寄付の控え（大きな「のこり」か「こえています」、上限の帯を寄付ごとに分けた絵、自治体の5つのマスで6つ目から赤、まだの申請書とあと何日）。同じ名前の自治体は1つ（全角半角・空白はそろえる）。保存できない端末でも計算は使える。年ごとに分けて保存し、記録のある年が2つあるときだけ年のえらび。「コピー」で控えの文、「ぜんぶ消す」は2回押す
  - 制度の変更点 `/furusato/seido/`（10/22。トップでは「ほかの計算」にたたむ）：寄付の年のマス（今年・来年。はじめは見た人のブラウザの年）をえらぶと、書類の中の年表で、変更ごとに「前から・この年・まだ」と、その年から変わる数。載せるのは総務省の資料で確かめたものだけ（`FURUSATO_SEIDO_SOURCES`）：2019年6月の指定制度（3割以下の地場産品）、2026年の寄付の控除の見直し、2026年10月からの自治体の基準（使えるお金を52.5%以上、2029年10月からの指定で60%）、2027年の寄付からの特例控除の193万円の上限（給与収入1億円ほど）。ポイントの付与の決まりはコーナーの決まりで載せない。1月1日に `YEAR` を次の年へ
  - 返礼品 `/furusato/henreihin/`（第3弾。しくみは上の「返礼品のページ」）：入口（はじめての1件と4つのカテゴリ）と、お米・肉・魚介・日用品 `/furusato/henreihin/<kome|niku|gyokai|nichiyouhin>/`（親は入口）。一覧は1万円あたりの量が多い順（同じなら寄付額が少ない順）で、寄付額のマス（1万・2万・3万円まで・すべて）でしぼる。量は名前から読めたものだけ出し、どう読んだか（5kg×3袋）を小さく出す。ふるさと納税の店（店のコードが f＋自治体の6けた）だけ。はじめての1件は、2万円まで・定期便でない・レビュー10件以上で、発送の時期が書いてあるものから。決まり：一覧の中は楽天へのリンクだけ（`rel="sponsored noopener"`、「楽天ふるさと納税で見る」）、AdSense を置かない（`noAds`）、一覧のすぐ上に「広告　楽天アフィリエイトを利用しています」、ページの下に楽天のクレジット（形を変えない）、画像は楽天のURLのまま（`<html data-ext="rakuten-img">`、5件目から lazy）、楽天と協力関係があるように見せない、自分と家族はリンク経由で申し込まない。`verify-dist.mjs` が広告の表示・クレジット・外へのリンクの行き先・sponsored・画像を点検する。トップ・サイトマップ・関連ツールには LIVE のときだけ出る

## 年が変わるとき

## 公開（deploy.yml）と IndexNow
- 公開のくわしいこと
  - 本番では、アップロードの前後に `scripts/indexnow.mjs` が動き、**中身が変わったページだけ**を IndexNow（Bing・Yandex・Naver・Seznam・Yep）に知らせる。前回の指紋は本番の `/indexnow-pages.json`、鍵は `SITE.indexnowKey`（ビルドが `/<鍵>.txt` を置く）。結果は Actions の注意書き（IndexNow）で見る。Google は IndexNow に入っていないので、サイトマップとリンクで見つけてもらう

## 公式のページの見張り（watch.yml）
- 公式のページの見張り（10/22 統合の設計）：`.github/workflows/watch.yml` が `scripts/watch-pages.mjs` を動かす（結果の数は Actions の注意書きにも出る）。3時間おきにお買い物マラソンの公式のページ（日付・時刻・「◯ポイント」「◯倍」の数字だけ）、毎日（朝6:53）に SPU の公式のページ（`SPU_SOURCES`。日付・「◯ポイント」「◯pt」「◯円」「◯倍」の数字だけ）、週1回（月曜の朝）にふるさと納税の出典のページ（本文の指紋だけ）を前回とくらべ、変わったら Issue（開いている同じ Issue があればコメント）。前回の数字は Actions のキャッシュ（リポジトリに入れない）。公式の文は保存しない・Issue に貼らない。Issue の対応は、毎日8:32の予約タスク「サクッと計算 公式ページの見張りの対応（Claude）」がする（10/22 しょーくん「見張りの部分は自動化できる？」）：開いている見張りの Issue と、ふるさと納税の出典の確認日（残り7日以内）と、本番の公開の失敗を gh api で見て、なければすぐ終わる。あれば公式を開いて確かめ、`src/data/point.mjs`・`src/data/spu.mjs`・`src/data/furusato.mjs`・ふるさと納税とマラソンと SPU のページの文・テストだけを直して PR → CI が緑なら Merge して、Issue を閉じる。計算のしくみ（`src/lib/`）まで変える必要があるときは Merge せずに報告

- 出典・外部リンクの点検（10/27 連絡 C-005）：`.github/workflows/check-links.yml` が `scripts/check-links.mjs` を動かす。ビルドしたページの外部リンクを GitHub から開く（WebFetch は古い写しで消えたページも開けるので）。src を変える PR はその PR で足した・変えたリンクだけで、結果は注記（PR は止めない）。毎週月曜7:41はぜんぶ（約110件）と、SPU・Amazon・買いまわり・ふるさと納税の確認日が残り14日のもの。404・ドメインなし・トップへ飛ばされた・確認日は Issue「出典の点検」にし、毎日8:32の予約タスクが同じ発行元の新しいページに差しかえる。403 や時間切れは消えたとは限らないので Issue にしない（書くだけ）。楽天の返礼品のリンクは API で作るので見ない

## 検索結果での見え方（説明文）
- 検索結果での見え方（10/26 全サイト共通の決まり。プロジェクトの `claude/site-principles.md`）：説明文（meta description）はページごとに、そのページの計算例・早見表・出典の日・件数から作る（数字は本文の計算例と同じ計算の値を入れて、データが変わると説明文も変わるように）。全角80〜120文字・数字を入れる・ほかのページと同じにしない・使わない言葉を入れない（`verify-dist.mjs` が点検。noindex のページはのぞく）。値段は `yenBand`（`src/lib/number.mjs`）で「2,500円台」「1万円台から」のような幅に。ツールの数は `CALC_COUNT`、いちばん新しい更新日は `LAST_UPDATED`（`src/tools.mjs`）。サイト名は、トップの WebSite の構造化データ（name と alternateName は `SITE`）と、全ページの og:site_name

## 入力した数字と外部の読み込み
- 計算はブラウザの中だけ。**入力した数字を送らない**。保存するのは3つだけで、どれもこの端末のブラウザの localStorage（送らない）：ちょいメモ（「メモする」を押したときの1行と日時）と寄付メモ `/furusato/memo/` と現場手帳 `/genba/`（`sakutto-genba`。現場10件と、印刷・画像で送るを押した回数と最初の日）（フッターの1行は `page({ footNote })` でそのページだけ差しかえる）。プライバシーポリシーにも書いた。外部のスクリプト・画像・フォントを読み込まない。例外はページの印 `<html data-ext>` で決めた2つだけ（10/22 統合の設計）：`adsense`＝AdSense のスクリプト（`SITE.adsense` に運営者IDを入れると、noindex と `noAds` のページをのぞく全ページに入り、ビルドが `/ads.txt` を置く。空のあいだは何も入らない）、`rakuten-img`＝返礼品のページの楽天の商品画像。2つを同じページに入れない。`verify-dist.mjs` が見張る
